## 3. 스택 켜고 끄기 (서버 안에서)

```bash
cd /opt/ada && git pull        # 항상 최신 코드 먼저
cd docker

# 전체 기동 (nginx 포함 — edge 프로파일 꼭 넣기)
docker compose --env-file ../.env --profile core --profile ml --profile edge up -d

# 중지
docker compose --env-file ../.env --profile core --profile ml --profile edge down
```

> **nginx(HTTPS)는 `edge` 프로파일에만 있음.** `--profile edge` 를 빼면 nginx 가 안 떠서 https 접속이 막힘.
>
> **로컬 개발 PC는 반대로 `edge` 를 빼고 켬** — 로컬은 `http://localhost` 로 직접 접속해
> 공개 서버를 통한 외부 노출 없이 개발하는 게 안전. 따라서 nginx 가 로컬 개발엔 불필요.

## 6. 일일점검 sudoers 등록 ✅ 등록 완료 (2026-06-10)

점검 스크립트가 sudo 로 `fail2ban-client` / `openssl` 을 호출하는데, `ada` 계정은 sudo 에 비밀번호가 필요해 cron(자동)에서 실패했음 → fail2ban/TLS 점검이 ⚠️ 로 떴음. 아래 규칙을 `/etc/sudoers.d/ada-check` 에 등록해 해결.

**재설치/복구 시 서버에서 1회 실행** (비밀번호 입력 필요):

```bash
echo 'ada ALL=(ALL) NOPASSWD: /usr/bin/fail2ban-client, /usr/bin/openssl' \
  | sudo tee /etc/sudoers.d/ada-check
sudo chmod 0440 /etc/sudoers.d/ada-check
sudo visudo -c -f /etc/sudoers.d/ada-check     # "parsed OK" 떠야 정상
```

확인: `/opt/ada/scripts/daily_check.sh` → fail2ban / TLS 가 ✅ 로 나옴 (등록 후 확인됨).
