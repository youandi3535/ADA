# 본문 풍부화 매트릭스 — 세계 대기업 비즈니스 의사결정 보고서 정공

> **보고서 정체성**: 비즈니스 의사결정 보고서 (큰 틀) + 데이터 분석을 근거로 사용 (한 부분)
> **본문 톤**: 80% 비즈니스 메시지 + 20% 데이터·통계
> **데이터 분석 상세**: 부록 9.1~9.8로 위임

## 우선순위 — 가성비 순

### 1순위 ★★★★★ — §7 비즈니스 함의 (가장 큰 임팩트)

추가할 블록:
- **재무 임팩트**: ROI · 페이백 기간 · NPV (모델 도입 비용 vs 효과)
- **운영 영향**: 인력 변화 · 시스템 통합 요구
- **단계별 마일스톤**: 5%→20%→100% 롤아웃 + 각 단계 게이트 조건
- **변화 관리**: 조직 저항 예상 · 소통 전략 · 교육 계획
- **벤치마크**: 업계 평균 · 경쟁사 도입 사례 (외부 데이터 필요 시 정형)

**데이터 의존성**: business_kpi (일부 있음), 나머지는 정형 템플릿 + 카테고리별 분기

### 2순위 ★★★★ — §8 결론

추가할 블록:
- **거버넌스**: 의사결정 권한자 명시 + 승인 절차 + 결재 시한
- **외부 환경 리스크**: 규제 · 법적 · 정치적 변동성 점검
- **CXO 시그니처 라인**: "Approved by ___ / Date ___" 형식 (시각적 결재 박스)

**데이터 의존성**: 거의 없음 — 정형 템플릿 + 사용자 입력

### 3순위 ★★★ — §1 분석 개요

추가할 블록:
- **비즈니스 맥락**: 시장 동향 · 경쟁 환경 · 소비자 변화 (business_context 강화)
- **이해관계자 분석**: 직접/간접 영향 받는 이해관계자 매트릭스
- **재무 기대치**: 기대 효과 정량 추정 (business_kpi 강화)

**데이터 의존성**: business_context (있음·짧음), 이해관계자는 정형 템플릿

### 4순위 ★★★ — §6 핵심 인사이트

추가할 블록:
- **비즈니스 임팩트 시뮬레이션**: 핵심 동인 통제 시 매출/비용 변화
- **세그먼트별 매출 환산**: per_segment의 size × value × rate

**데이터 의존성**: per_segment 활용 (있음)

### 5순위 ★★ — §3 EDA, §2 데이터 이해

§3 EDA:
- 세그먼트별 수익·비용 환산 (단순 차트 추가가 아니라 비즈니스 의미)

§2 데이터 이해:
- 운영 환경에서 데이터 활용 가능성 평가

**데이터 의존성**: 일부 정형 가능

### 가볍게 유지 (상세는 부록으로 위임) ★

- **§4 분석 방법**: 핵심 메시지만, 상세는 부록 9.1
- **§5 모델 성능**: 핵심 지표만 + 운영 신뢰성 한 줄, 상세는 부록 9.3

## 데이터 의존성 정리

| 항목 | ctx 데이터 | 필요 작업 |
|---|---|---|
| 비즈니스 맥락 | business_context (있음·짧음) | 정형 보강 + 카테고리별 분기 |
| 이해관계자 | ❌ 없음 | 정형 템플릿 (분류·이상·시계열·회귀별) |
| ROI·페이백 | business_kpi (일부) | 모델 도입 비용 추정 정형 |
| 시나리오 A/B/C | ✅ 이미 있음 ([DecisionFrame]) | 그대로 |
| 운영 영향 | ❌ 없음 | 정형 템플릿 |
| 마일스톤 | ❌ 없음 | 정형 (분기 게이트) |
| 변화 관리 | ❌ 없음 | 정형 템플릿 |
| 거버넌스 | classification (있음) | 정형 + 사용자 입력 (대시보드) |
| 외부 환경 | ❌ 없음 | 정형 (도메인별 일반) |
| 벤치마크 | ❌ 없음 (지금 못 함) | 외부 데이터 필요 또는 정형 안내 |

→ 대부분 **정형 템플릿 + 카테고리별 분기**로 자동 가능. 외부 데이터(벤치마크) 영역은 사용자 입력으로.

## 작업 옵션 (사용자가 결정)

### 옵션 A: 풀 풍부화 (1~4순위 다 적용)
- 시간: 큼
- 효과: 100% — 세계 대기업 정공 수준
- 페이지: +5 (32~36 페이지)

### 옵션 B: 1+2순위만 (§7·§8 강화)
- 시간: 중
- 효과: 80% — 가장 임팩트 큰 두 섹션
- 페이지: +3 (30~34 페이지)

### 옵션 C: 1순위만 (§7 함의 풍부화)
- 시간: 작음
- 효과: 60% — ROI·페이백·변화관리·마일스톤
- 페이지: +2 (29~33 페이지)

### 옵션 D: 부분 (제가 우선순위 추천 → 사용자 보고 결정)
- 가장 데이터 의존성 적고 임팩트 큰 5개만:
  1. §7 ROI·페이백 정량
  2. §7 단계별 마일스톤
  3. §8 거버넌스 박스
  4. §1 이해관계자 표
  5. §6 비즈니스 임팩트 시뮬레이션
