# ADA PDF — 사용자측 처리 항목 + 100점 가는 길

> 이 문서는 **자동 코드로 해결 안 되는 항목**과 **대시보드/외부에서 처리할 사항**을 정리합니다.
> 다음 표지·디자인 작업이 100점 가까이 가려면 이 항목들이 채워져야 합니다.

## 1. 대시보드 옵션 — 사용자 입력으로 받아야 할 항목

### 1-1. 분류 등급 (Classification)

현재 코드: `ctx.meta.classification` 으로 표지·헤더 자동 박힘.
세계 정공 3단계:

| 등급 | 의미 | 표시 | 적용 케이스 |
|---|---|---|---|
| `CONFIDENTIAL` | 기밀 — 사내 임원·결재선만 | 빨간 굵게 | 인수합병·민감 고객·내부 전략 |
| `INTERNAL` | 사내 — 부서 내 공유 가능 | 회색 굵게 | 일반 분석 보고서 (디폴트) |
| `PUBLIC` | 외부 공유 가능 | 회색 굵게 | 공개 데이터·마케팅 결과 |

**대시보드 액션**:
- CSV 업로드 페이지에 `분류 등급` 드롭다운 추가 (3개 옵션, 디폴트 INTERNAL)
- ctx 빌더에서 `ctx.meta.classification = 사용자_입력` 전달

### 1-2. 보고서 부제 / 사용자 제목

현재 코드: `ctx.meta.user_intent` 가 표지 큰 제목으로.
세계 정공:
- 사용자가 분석 의도·제목을 직접 입력 (예: "Q4 고객 이탈 원인 분석")
- 그 입력이 표지 큰 제목으로

**대시보드 액션**:
- CSV 업로드 시 `보고서 제목` 텍스트박스 추가 (필수)
- 옵션으로 `분석 의도 한 줄` (부제용)

### 1-3. 작성자 / 부서 정보

세계 정공: 표지에 "Prepared by: [Name/Team]"

**대시보드 액션**:
- 사용자 회원 정보에서 이름·부서 자동 채움
- 옵션으로 보고서별 다른 작성자 입력 허용

### 1-4. 대상 / 배포처

세계 정공: "Prepared for: [Client / Stakeholder]"

**대시보드 액션**:
- 옵션 텍스트박스 (선택 입력)
- 빈칸이면 표시 안 함

## 2. 외부 자산 — 디자이너·이미지 제공 필요

### 2-1. ADA 로고 이미지 (`.png`)

현재: 표지에 "ADA Studio" 텍스트만.
세계 정공: 실제 로고 이미지 (transparent .png).

**필요 자산**:
- `ADA_logo_white.png` (네이비 박스 안에 들어갈 흰색 버전)
- `ADA_logo_color.png` (본문 페이지 헤더용 컬러)
- 권장 해상도: 600px × 200px (3:1 비율)

**적용 위치**:
- 표지 좌상단 네이비 박스 안 (ADA Studio 텍스트 → 로고 이미지)
- 본문 페이지 헤더 좌상단

**코드 작업**:
1. `outputs/assets/` 폴더에 .png 배치
2. `pdf_carrier.py` 의 `_foot` 함수에서 `canvas.drawImage()` 사용
3. 텍스트 fallback 유지 (이미지 없으면 텍스트)

### 2-2. ADA 아이콘 / 시각 요소

세계 정공: 작은 아이콘·차트·일러스트로 시각 임팩트.

**필요 자산** (선택):
- 글로브 아이콘 (사이트 메인 페이지 그것) — 16×16 / 32×32 px
- 데이터 분석 메타포 아이콘 (차트·돋보기 등)

## 3. 100점 가는 길 — 자동 코드 영역

### 3-1. 표지 (현재 92→97 가능)

| 항목 | 현재 | 목표 | 작업 |
|---|---|---|---|
| 큰 숫자 시각 요소 | 카테고리 컬러 아이콘 | 미니 도넛/막대 차트 | matplotlib로 작은 PNG 생성·박기 |
| 부제 시각 위계 | 16pt 네이비 | 동일 + 좌측 시안 강조 막대 | 작은 컬러 막대 prefix |
| 타이포 미세 조정 | 자동 | 디자이너 손본 수준 | 자간·줄 간격 픽셀 조정 |

### 3-2. 본문 페이지 (현재 85→92 가능)

| 항목 | 작업 |
|---|---|
| 컬러 팔레트 통일 | 카테고리별 색 → ADA 네이비 + 시안 1세트로 통일 (브랜드 일관) |
| 헤더 페이지번호 추가 | 우상단 분류등급 옆에 `p.X / Y` 진행도 표시 |
| 푸터 디자인 | 옅은 라인 + 회사 정보 / 페이지번호 / 날짜 3분할 |

### 3-3. 부록 (현재 88→95 가능)

| 항목 | 작업 |
|---|---|
| 부록 표지 (9.0) | 8개 부록 미니 썸네일 + 본문 참조 표 |
| 각 부록 헤더 | "9.N | 본문 §X 검증" 더 명확하게 |
| Risk Matrix 디자인 | 사분면 색·점 디자인 정교화 |
